# ColoredHex
 ## Description
 **ColoredHex** - is a chat plugin that highlights and visually displays color codes in three formats: HEX, RGB, and HSL. It detects color codes in messages and renders them in their actual color, making it easier to use Discord without the hassle of constantly googling color values.
