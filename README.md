### ✨ What does ColoredHex do?

The plugin automatically detects color codes in messages and displays them with their **actual color**:
- **#rrggbb / #rgb** (HEX)
- **rgb(255, 128, 0) / rgba(...)**
- **hsl(180, 100%, 50%) / hsla(...)**

No more copying a code → opening a color picker → checking what color it is. See it instantly.

**Examples:**
- `#FF0000` → Vivid Red
- `rgb(46, 204, 113)` → Emerald Green
- `hsl(271, 76%, 53%)` → Deep Purple

**Available options:**
* Toggle individual formats (HEX, RGB, HSL)
* Customize preview size (Square / Circle / Strip)
* Show/hide text code next to the color
* Adjustable corner rounding
* Transparency support for rgba/hsla
* Case-insensitive HEX support (Uppercase/Lowercase)
* Ignore codes within spoilers, code blocks, or embeds (Optional)

### 🚀 Installation

#### BetterDiscord
1. Download the latest version from [Releases](https://github.com/Keyser2356/ColoredHex/blob/main/ColoredHex.plugin.js).
2. Move the `.plugin.js` file into your **Plugins** folder.
3. Enable it in your BetterDiscord settings.
